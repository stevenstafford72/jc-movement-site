# JC Movement Website

Official website for **J.C. Movement Inc.**, a nonprofit organization focused on youth development and community outreach in Nashville, Tennessee.

Live Site: https://jcmovement.org/

---

## Overview

This project serves as the central platform for J.C. Movement to share program information, updates, and community initiatives. The site is updated periodically to reflect changes in programs such as after-school care, summer camps, and organizational updates.

---

## Tech Stack

* Next.js (App Router)
* TypeScript
* Tailwind CSS
* Vercel (Deployment)

## Getting Started

Clone the repository:

```
git clone https://github.com/stevenstafford72/jc-movement-site.git
cd jc-movement-site
```

Install dependencies:

```
npm install
```

Run locally:

```
npm run dev
```

---

## Updates and Maintenance

The site is updated as needed based on program changes, seasonal offerings, and organizational needs. Updates are deployed through Vercel following local testing.
